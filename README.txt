PALESTRA MICHELE — PUBBLICAZIONE GRATUITA CON GITHUB PAGES

Serve un account GitHub (gratuito), non Netlify.
1. Vai su https://github.com/new e crea un repository PUBLIC chiamato palestra-michele.
2. Nel repository seleziona Add file > Upload files e carica i file ESTRATTI dallo ZIP (index.html, manifest.webmanifest, sw.js e le tre icone). Non caricare solo lo ZIP.
3. Fai Commit changes.
4. Vai in Settings > Pages > Build and deployment. Scegli Deploy from a branch, branch main, cartella /(root), Save.
5. Il sito sara su https://TUO-USERNAME.github.io/palestra-michele/ dopo la pubblicazione.
6. Aprilo su Safari iPhone > Condividi > Aggiungi alla schermata Home.
7. Per gli aggiornamenti futuri: sostituisci i file nel MEDESIMO repository; il link resta uguale.

ATTENZIONE: GitHub Pages su repository pubblico rende visibili a chiunque sito e dati incorporati, anche senza conoscere il link. Non caricare dati sensibili se vuoi mantenerli privati.
Inviare i dati in ChatGPT NON aggiorna automaticamente GitHub. Occorre pubblicare la versione aggiornata nel repository.
